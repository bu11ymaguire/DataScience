## **프로그래밍 과제 #2: 의사결정 나무(Decision Tree) 분류기 구현**

### **1. 프로젝트 개요**
* **목표**: 학습 데이터셋을 사용하여 의사결정 나무(Decision Tree) 모델을 구축하고, 이를 기반으로 테스트 데이터셋의 클래스를 분류하는 프로그램을 작성해야 합니다.
* **사용 언어**: Python.
* **실행 환경**: Windows, Mac OS, 또는 Linux 환경을 지원해야 합니다.

### **2. 실행 명령어 및 환경 설정**
* **실행 파일명**: `dt.py` (또는 `.exe`) 형태로 작성해야 합니다.
* **명령어 인자(Arguments)**: 프로그램 실행 시 3개의 인자(학습 파일명, 테스트 파일명, 출력 파일명)를 반드시 순서대로 전달받아야 합니다.
    * > **실행 예시**: `python dt.py dt_train.txt dt_test.txt dt_result.txt`
* **파일 위치**: 실행 파일, 입력 파일(train/test), 출력 파일(result)은 모두 동일한 폴더 내에 있어야 합니다. 폴더 경로가 다르게 설정될 경우 0점 처리됩니다.

### **3. 데이터셋 및 알고리즘 요구사항**
* **범용성**: 하드코딩 없이 어떤 범주형(Categorical) 데이터셋이 주어지더라도 처리할 수 있도록 범용적으로 구현해야 합니다 (연속형 변수는 없음).
* **학습 세트 형식**:
    * 첫 번째 줄은 $n$개의 속성(Attribute) 이름입니다.
    * 마지막 속성(`[attribute_n]`)은 해당 데이터(Tuple)의 클래스 라벨(Class label)입니다.
* **테스트 세트 형식**: 학습 세트와 동일한 형식이지만, 마지막 열인 클래스 라벨(`[attribute_name_n]`)이 존재하지 않습니다.
* **속성 선택 척도(Attribute Selection Measure)**: 노드를 분할할 때 다음 세 가지 기준 중 하나를 사용해야 합니다: Information gain, Gain ratio, Gini index.

### **4. 출력 파일(Output) 요구사항**
* **형식 일치**: 출력 형식에 맞지 않으면 점수를 받을 수 없으므로 주의해야 합니다.
* **구분자**: 파일의 데이터 값과 속성들을 구분할 때는 반드시 탭(`\t`) 문자를 사용해야 합니다.
* **출력 내용**:
    * 첫 줄: 테스트 세트의 속성 이름들과 마지막에 예측할 클래스 라벨의 이름을 포함해야 합니다.
    * 데이터 행: 주어진 테스트 세트의 속성 값들 뒤에, 프로그램이 예측한 클래스 라벨 값을 이어서 출력해야 합니다.
* **순서 유지(중요)**: 테스트 세트에 주어진 데이터(Tuple)의 순서를 절대 변경하면 안 됩니다. 정답과 비교하기 위해 원래의 순서를 그대로 유지하여 출력해야 합니다.
