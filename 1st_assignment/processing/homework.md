## 📄 데이터 포맷

1. 입력 파일 포맷 (`.txt`) 

* 파일의 각 줄(Row)은 하나의 트랜잭션(transaction)을 나타냄 


* 각 아이템 ID(item id)는 숫자 값(numerical value)으로 구성됨 


* 각 트랜잭션 내에서 아이템은 중복되지 않음 



2. 출력 파일 포맷 (`.txt`) 

* 
**출력 형태**: `[item_set] [associative_item_set] [support(%)] [confidence(%)]` 


* 
**아이템 셋 표기**: 반드시 중괄호(`{}`)를 사용하여 표기해야 함 (예: `{0}`, `{0.4}`, `{0,3,1}`) 


* 
**지지도 (Support)**: 트랜잭션이 `[item_set] U [associative_item_set]`을 포함할 확률 


* 
**신뢰도 (Confidence)**: `[item_set]`을 가진 트랜잭션이 `[associative_item_set]`도 포함할 조건부 확률 


* 
**숫자 형식**: 지지도와 신뢰도 값은 소수점 둘째 자리까지 반올림하여 표기해야 함 (예: 24.631은 24.63으로 표기) 


* 출력되는 연관 규칙의 순서는 무관함 


* 
**주의사항**: 출력 포맷을 지키지 않을 경우 추가 감점이 있으며, 형식이 올바르지 않으면 0점 처리됨
