데이터 마이닝(Data Science) 세 번째 프로그래밍 과제인 'DBSCAN 클러스터링 구현'의 주요 요구사항은 다음과 같습니다.

**1. 과제 목표 및 개발 환경**
*   **목표:** 주어진 데이터셋에 대해 **DBSCAN 알고리즘을 직접 구현하여 클러스터링을 수행**하는 것입니다.
*   **개발 환경:** Windows, Mac OS, Linux 환경에서 **Python** 언어를 사용해야 합니다.
*   **실행 파일명:** 반드시 `clustering.py` 또는 `clustering.exe`로 제출해야 합니다.

**2. 입력 및 실행 조건**
*   프로그램은 **입력 데이터 파일명, n, Eps, MinPts**의 총 4가지 인자(argument)를 받아 실행되어야 합니다.
*   입력 데이터의 형식은 `[객체 ID]\t[x좌표]\t[y좌표]\n` 형태입니다.
*   총 3개의 입력 데이터가 주어지며, 권장되는 클러스터 수(n), 최대 반경(Eps), 최소 점의 수(MinPts) 파라미터는 다음과 같습니다.
    *   `input1.txt` : n=8, Eps=15, MinPts=22
    *   `input2.txt` : n=5, Eps=2, MinPts=7
    *   `input3.txt` : n=4, Eps=5, MinPts=5

**3. 출력 파일 요구사항**
*   각 입력 데이터에 대해 **n개의 출력 파일을 생성**해야 합니다. 
*   **파일 명명 규칙:** `input#_cluster_0.txt` 부터 `input#_cluster_n-1.txt` 까지의 이름으로 생성되어야 합니다 (예: input1_cluster_0.txt).
*   **출력 내용:** 각 파일에는 해당 클러스터에 속하는 객체의 ID들만 줄바꿈(`\n`)으로 구분하여 저장합니다.
*   **예외 처리:** 만약 알고리즘이 찾은 클러스터 수(m)가 요구되는 n개보다 많다면, 클러스터 크기(객체 수)가 작은 순서대로 (m-n)개의 클러스터를 제거하여 개수를 맞출 수 있습니다. 아웃라이어(Outlier)는 특정 클러스터에 포함시키지 않고 제거해도 무방합니다.

    *   기타 구현 및 테스트 사양

**5. 평가 및 감점 규정**
*   **평가 방식:** Kendall's tau 측정법과 유사하게 '(맞게 분류된 쌍의 수) / (가능한 전체 쌍의 수)'로 점수가 계산됩니다. 정상적으로 구현 시 input 1, 2, 3에 대해 각각 99점, 95점, 99점과 유사한 점수가 나와야 합니다.
*   **감점 기준:**
    *   제출 지각: **100% 감점**
    *   조교가 주어진 지침대로 컴파일에 실패할 경우 패널티가 부과됩니다.
    *   그 외 요구사항 미충족 시 최대 **30%의 감점**이 주어질 수 있습니다.
